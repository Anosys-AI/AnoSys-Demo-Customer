# Anosys Observability Report - Variables Documentation

This document describes all variables and custom fields (CVs) sent to Anosys for observability and tracking.

## Core Metadata Fields

| Variable | Description |
| :--- | :--- |
| `timestamp` | The Unix timestamp in milliseconds when the event was generated. |
| `user_timestamp` | The Unix timestamp as a number for temporal analysis. |
| `event_type` | The category of the event (e.g., `chatkit chat`, `message.action`). |
| `event_source_name` | The source system generating the event (e.g., `chatkit`, `chatkit action`). |
| `event_id` | The OpenAI Workflow ID associated with the interaction. |

---

## Custom Variables (CVS - String & CVN - Numeric)

### Chat Interaction Events
These variables are mapped in `mapChatkitLogsToAnosys` from chat thread logs.

| Field ID | Friendly Name | Description |
| :--- | :--- | :--- |
| **`cvs1`** | **User Prompt** | The last text message sent by the user in the interaction. |
| **`cvs2`** | **Assistant Response** | The text response generated by the AI assistant. |
| **`cvs3`** | **Application Session ID** | A unique UUID representing the current browser/app session. |
| **`cvs4`** | **Chat Thread ID** | The unique ID of the OpenAI ChatKit thread. |
| **`cvn1`** | **Response Duration** | Total time taken for the LLM to complete its response (in ms). |
| **`cvn2`** | **Time to First Token** | Latency between user submission and the first token of response (in ms). |

#### Sequential Message Details (Starting from `cvs10`)
For each message in a chat turn, the following fields are populated sequentially:

| Field Pattern | Friendly Name | Description |
| :--- | :--- | :--- |
| `cvs[10, 14, 18...]` | Message Kind | Type of message: `prompt`, `response`, or `thought`. |
| `cvs[11, 15, 19...]` | Message Item ID | Unique identifier for the specific message item in the thread. |
| `cvs[12, 16, 20...]` | Created At | Timestamp of when the message was created. |
| `cvs[13, 17, 21...]` | Message Content | The full text content of the message or summary of thoughts. |

---

### UI Action Events
These variables are sent when a user interacts with UI elements (e.g., message actions).

| Field ID | Friendly Name | Description |
| :--- | :--- | :--- |
| **`cvs1`** | **Action Name** | The specific action performed (e.g., `copy`, `retry`). |
| **`cvs2`** | **Raw Event Data** | Full JSON string of the event payload for deep inspection. |
| **`cvs3`** | **Application Session ID** | A unique UUID representing the current browser/app session. |
| **`cvs4`** | **Chat Thread ID** | The unique ID of the OpenAI ChatKit thread. |
